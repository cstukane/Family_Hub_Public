# GLOSSARY  Kitchen Hub

- **HTMX**: JS library enabling HTML-over-the-wire partial updates without a SPA.
- **Adapter**: Provider-specific module implementing a standard interface (e.g., weather).
- **Service**: Business logic layer that uses adapters and caching.
- **Partial**: A server-rendered HTML fragment swapped into the page (HTMX).
- **Kiosk Mode**: Fullscreen browser session launched at boot.
- **TTL**: Time-To-Live for cached items.
